# XDRemux v0.4.0-pre.8

这是 v0.4.0 的第 8 个预发布测试版本，重点引入照片 EXIF/HDR 详情弹窗、Live Photo 双码流与音频轨道深度检视与 QuickTime 规范对齐，并重构实况照片默认策略与物化文件保留生命周期。

## 本版本更新

- **照片详情弹窗 (Photo Details Dialog)**：
  - **EXIF 拍摄参数解析**：
    - 全面解析机型、光圈 (f-number)、快门速度、ISO 感光度、物理焦距与 35mm 等效焦距、曝光补偿、拍摄日期时间与画面像素分辨率。
  - **HDR 动态范围与头房 (Headroom) 检视**：
    - 精确展示 ProXDR 格式（LHDR / UHDR）、GainMap 最大增益值（EV）以及 EDR 屏幕高光亮度倍率。
  - **交互与跨平台适配**：
    - 桌面端队列卡片增加详情快捷入口，移动端列表卡片提供“照片详情”菜单选项。
    - 宽屏以居中弹窗展示，窄屏/移动端自适应为半屏底部动作抽屉。
    - 支持一键“复制全部信息”格式化导出到剪贴板，方便用户比对与排查。

- **Live Photo 双码流、音轨检视与 QuickTime 规范对齐**：
  - **媒体流与音轨深度检测**：
    - 自动识别实况照片是否包含音轨（如 AAC/mp4a 编码、单声道/立体声、采样率及音轨时长）。
    - 识别 4K/1080P 视频分辨率、视频编码（HEVC/HVC1、H.264）、帧率、总帧数及封面静帧微秒级呈现时间点。
    - 识别 OPPO/OnePlus 双码流架构（4K 高清主流 + 1080P 预览流）。
  - **Apple Live Photo 规范对齐 (`tref` / `cdsc`)**：
    - 在生成的 Live Photo 媒体元数据轨道中加入 `tref` -> `cdsc` 原子，精准指向对应视频轨道 ID，完全符合 Apple Live Photo 的 timed metadata 规范。
    - 增强静帧时间戳越界容差（轻微漂移自动吸附视频末尾，避免合成中断）。

- **实况照片处理策略重组与默认行为优化**：
  - **默认行为调整为「Live Photo 合成」**：移除不合理的默认“跳过”行为，导入实况照片后默认直接合成 Apple Live Photo 配对文件。
  - **策略选项精简与重排**：
    1. **Live Photo 合成**（默认，生成 HEIC + MOV Live Photo 配对）
    2. **仅静帧**（仅转换静态照片，跳过动态视频）
    3. **拆分静帧 + 视频**（转换静态照片，并提取独立 MP4 视频）
    - 彻底移除冗余的 `skip` 选项，简化交互。

- **断点与临时输入物化生命周期修复**：
  - 修复“转换完成后打开设置修改任意参数重新转换时提示文件不可用”的问题。
  - 临时物化文件的清理机制改为队列感知（Queue-Retention-Aware）：只要队列中仍有该文件的待处理/已完成卡片，输入临时文件将持续保留，仅在卡片被显式移除或队列清空时才安全清理。

## 验收重点

1. **照片详情查看与复制**：点击任意照片卡片上的“详情”按钮，验证 EXIF 拍摄参数、分辨率、HDR GainMap 增益与实况流信息准确呈现，点击“复制全部信息”能正确粘贴到其他应用。
2. **实况照片合成与音轨对齐**：导入含音频的实况照片，验证卡片显示音轨信息与分辨率标签（如 4K、双码流），默认以“Live Photo 合成”模式转换，并在 Apple 设备或照片应用中验证实况播放与声音。
3. **改参数后再次重转**：对已转换完成的照片，修改任意设置并点击重新转换，验证不再报错文件不存在或不可用。
