# 6.4.10 概览图像 (Overview images)

概览图像由网格派生图像项、或瓦片化预派生编码图像项、或瓦片化图像项描述，其重建图像是通过生成基础图像项重建图像的较低分辨率、“合并（binned）”版本而形成的。基础图像项也是瓦片化的。瓦片化可以使用特定编解码器的特征来实现，或者通过使用网格派生图像项来实现，或者通过使用瓦片化图像项来实现。当使用网格派生图像项时，网格的输入项定义了瓦片。派生图像项不应用作图像网格的输入，因为内容需要就地字节范围访问。单个瓦片应在内存中连续写入，从而允许通过单个读或写操作进行访问。

使用特定编解码器特征进行瓦片化的表示概览图像的预派生编码图像项或表示基础图像的图像项，其存储方式应使每个 extent 标识出对应于瓦片的数据范围，并应与指示对 extent 的约束并描述瓦片化网格的 ConstrainedExtentsGridProperty 相关联。

如果合并后的分辨率在行（列）末尾导致分数或不完整的瓦片，则一排（一列）瓦片中的最后一个瓦片应在行（列）末尾用零值填充，以完成该行（列）中的最后一个瓦片。如果需要，可应用干净光圈变换属性（'clap'）来裁剪填充的行和/或列。一排（一列）瓦片中的瓦片数量是通过将概览图像的宽度（高度）除以 X 方向的瓦片尺寸（Y 方向的瓦片尺寸）并向上取整来确定的。

概览图像的图像格式与基础图像相同。即波段数、比特深度、颜色格式等。

# 6.5.41 约束范围网格 (Constrained extents grid)

# 6.5.41.1 定义

<table><tr><td>盒类型:</td><td>&#x27;cexg&#x27;</td></tr><tr><td>属性类型:</td><td>描述性项属性</td></tr><tr><td>容器:</td><td>ItemPropertyContainerBox</td></tr><tr><td>强制性 (每个项):</td><td>否</td></tr><tr><td>数量 (每个项):</td><td>最多一个</td></tr></table>

ConstrainedExtentsGridProperty 描述性项属性指示 itemLocationBox 中关联图像项的每个 extent 都被约束为包含该项的数据单元，这些单元可作为连续的字节范围提取，并且可独立解码和渲染为图像瓦片。

独立解码每个 extent 所需的配置数据可能存在于 ConstrainedExtentsGridProperty 内的 ExtentDecoderConfigurationRecord 中。如果 ConstrainedExtentsGridProperty 中不存在配置数据，则配置解码器并解码图像瓦片所需的所有数据单元或属性应在与图像项关联的解码器配置和初始化属性中声明。

关联图像项的重建图像是由较大画布内按给定网格顺序的一个或多个图像瓦片形成的。

对应于 extent 的图像瓦片按行优先顺序（首行优先，自左向右）插入，插入顺序为 ItemLocationBox 内关联图像项的 extent 顺序。ItemLocationBox 内的 extent_count 值应等于 $(1+\text{rows\_minus\_one})$ * $(1+\text{columns\_minus\_one})$。所有图像瓦片应具有完全相同的宽度和高度，即 image_tile_width 和 image_tile_height。重建图像是通过将图像瓦片拼接（tiling）成网格而形成的，该网格的列宽等于 image_tile_width，行高等于 image_tile_height，无间隙或重叠。图像瓦片网格应完全“覆盖”关联图像项的重建图像，其中 image_tile_width*columns 大于或等于 image_width，且 image_tile_height*rows 大于或等于 image_height，其中 image_width 和 image_height 在与图像项关联的 ImageSpatialExtentsProperty 中被指明。

flags 字段用于指示图像瓦片相关信息。定义了以下 flags 值。

0x000001 field_length_flag：当设置为 1 时，指定字段 image_tile_width 和 image_tile_height 的长度为 32 位。当 field_length_flag 设置为 0 时，指定字段 image_tile_width 和 image_tile_height 的长度为 16 位。

0x000002 tile_config_info_present_flag：当设置为 1 时，指定独立解码每个 extent 所需的解码器配置数据存在于 ConstrainedExtentsGridProperty 中。当 tile_config_info_present_flag 设置为 0 时，独立配置解码器并解码 extent 所需的所有数据单元或属性应在与图像项关联的解码器配置和初始化属性中声明。

# 6.5.41.2 语法

```javascript
aligned(8) class ConstrainedExtentsGridProperty extends ItemFullProperty('cexg', version = 0, flags) { // 这是一个临时的非解析变量 unsigned int FieldLength = ((flags & field_length_flag) + 1) * 16; unsigned int(16) rows_minus_one; unsigned int(16) columns_minus_one; unsigned int(FieldLength) image_tile_width; unsigned int(FieldLength) image_tile_height; if (flags & tile_config_info_present_flag) { ExtentDecoderConfigurationRecord() extent_config; } 
```

# 6.5.41.3 语义

image_tile_width, image_tile_height：分别指定图像瓦片的宽度和高度（以像素为单位）。

rows_minus_one, columns_minus_one：指定图像瓦片的行数以及每行的图像瓦片数。该值分别比行数或列数少 1。包含在 extent 中的图像瓦片按照 extent 的顺序先填充顶行，然后填充第二行及后续行。

ExtentDecoderConfigurationRecord 是解码相应 extent 所需的解码器配置记录。解码器配置记录由用于对 extent 数据进行编码的图像编码格式具体指定并定义。

# 6.5.43 立体不适因子 (Stereo aggressors)

# 6.5.43.1 定义

盒类型: 'stag'

属性类型: 描述性项属性

容器: ItemPropertyContainerBox

强制性 (每个关联标识符值): 否

数量 (每个关联标识符值): 零个或多个

立体不适因子描述性项属性指定了在立体对中检测到的立体不适因子的存在及特征。立体不适因子被标识为在立体显示器上观看立体对时可能引起不适的元素。该项属性允许详细识别和表征这些不适因子。

该项属性在存在时，应与表示立体对的图像项或实体组一起使用。只有当这些不表示立体对的项也属于立体对实体组时，它才能与这些项相关联，从而明确其适用的立体上下文。如果与立体对实体组（'ster' 或 'stem'）相关联，则 'unif' 品牌应存在于兼容品牌中。

如果该项属性除了立体对实体组外，还与另一个项相关联，它可以用作提示，表明属性描述的不适因子局限于该特定项。例如，这可用于指示“镜头遮挡”仅存在于左或右图像项中，或者通过使用区域项指示存在于图像项的特定区域中。多个立体不适因子属性可以与同一个表示立体对的图像项或实体组相关联，因为并非所有不适因子都局限于同一区域。

注 1 图像项可以与多个立体对实体组相关联；然而立体不适因子只能应用于特定的实体组，这就是为什么要求立体不适因子必须与立体对实体组相关联。

注 2 由于立体不适因子的定位是通过项属性关联来指示的，因此单个 'StereoAggressorsProperty' 盒内的所有立体不适因子需要共享相同的定位。指定多个唯一的定位需要使用多个 'StereoAggressorsProperty' 盒。

aggressor_severity 应解释如下：

— 值为 0 表示严重程度未知。文件创建者对读取器没有建议。

— 1 到 42（含）的值表示轻微的严重程度。文件创建者建议，当以立体方式观看时，应警告敏感观众可能存在不适感。

— 43 到 84（含）的值表示中等严重程度。文件创建者建议，当以立体方式观看时，应警告所有观众可能存在不适感。

— 85 到 127（含）的值表示高等严重程度。文件创建者建议，当以立体方式观看时，应警告所有观众可能存在不适感，并且默认应使用单声道（2D）显示而不是立体显示，除非被观众手动切换覆盖。

如果没有为特定的不适因子指定 sub_type_uri，则 aggressor_severity 仅是一个相对量度，用于提供上述给观众的建议，并对文件中的不适因子进行相对排序。如果为不适因子指定了 sub_type_uri，则 aggressor_severity 应是一个可在文件之间进行比较的绝对量度。

# 6.5.43.2 语法

```txt
aligned(8) class StereoAggressorsProperty extends ItemFullProperty('stag', version = 0, flags = 0) {
    unsigned int(8) aggressor_count_minus_one;
    for (int i = 1; i <= aggressor_count_minus_one + 1; i++) {
    unsigned int(8) aggressor_type;
    unsigned int(1) sub_type_present;
    unsigned int(7) aggressor_severity;
    if (sub_type_present) {
    utf8string sub_type_uri;
    }
    }
} 
```

# 6.5.43.3 语义

version 应等于 0。

aggressor_count_minus_one 是不适因子数量减 1。

aggressor_type 的值在表 1 中定义。

aggressor_severity 提供了文件创建者认为不适因子严重程度的指示。如果未定义 sub_type_uri，则该严重程度是相对于文件而言的，不能用于比较不同文件之间不适因子的严重程度。

sub_type_uri 是一个可选的、以空字符结尾的 UTF-8 字符串，表示统一资源标识符 (URI)，用于更明确地识别立体不适因子的类型以及如何解释 aggressor_severity。如果指定，则 aggressor_severity 应为可在文件之间进行比较的绝对度量。如果不存在，则默认为空字符串。

# 6.6.2.4 色调映射派生 (Tone-map derivation)

# 6.6.2.4.1 定义

具有项类型（item_type）值为 'tmap' 的项定义了一个派生图像项，其重建图像是由一个基础输入图像和一个被称为增益图输入图像的辅助输入图像形成的。

输入图像由 ItemReferenceBox 内此派生图像项的 'dimg' 类型的 SingleItemTypeReferenceBox/SingleItemTypeReferenceBoxLarge 提供。在 'dimg' 类型的 SingleItemTypeReferenceBox/SingleItemTypeReferenceBoxLarge 中，from_item_ID 的值标识类型为 'tmap' 的派生图像项，reference_count 的值应等于 2，且 to_item_ID 的值标识输入图像，其中第一个应为基础输入图像，第二个应为增益图输入图像。如 ISO 21496-1 中所述，增益图输入图像可以具有与基础图像不同的尺寸。

通过根据 ISO 21496-1 中描述的算法将增益图应用于基础图像来完成重建。如 ISO 21496-1 中进一步描述的，增益图在应用期间可以通过权重进行缩放，以适应本地观看条件。

基础输入图像项应与 'colr' 项属性相关联。这对应于 ISO 21496-1 中描述的基线图像色度学元数据（baseline image colorimetry metadata）。

增益图输入图像项应与 'nclx' 类型的 'colr' 项属性相关联，这指示编码器为提高压缩率而进行的任何变换。在此项属性中，colour_primaries 和 transfer_characteristics 应设置为 2。full_range_flag 可以设置为 1 或 0。如果 full_range_flag 为 0，则读取器在应用 matrix_coefficients 和 full_range_flag 后，应将增益图像素值剪裁（clip）到逻辑范围 0.0 到 1.0。

一个 'tmap' 派生图像项应与 'colr' 项属性相关联。这对应于 ISO 21496-1 中描述的替代图像色度学元数据（alternate image colorimetry metadata），该元数据描述了在完全应用增益图输入项时（即权重为 1.0 或 -1.0，具体取决于增益图元数据）重建图像的颜色属性。

当 'tmap' 派生图像项是另一个派生图像项的输入时，该派生图像项应将 'tmap' 派生图像项的重建图像视为增益图已完全应用，并具有与 'tmap' 派生图像项关联的 'colr' 项属性的颜色属性。

基础输入图像和 'tmap' 派生图像项应视情况与 'clli' 项属性关联，以进一步记录每种表示的最佳观看条件。

一个 'tmap' 派生图像项应与 PixelInformationProperty 项属性关联。该属性为解码器提供了一个提示，说明在完全应用增益图后可用的近似颜色分辨率量。

增益图输入项中的通道数可以与 'tmap' 派生图像项主体中的 gain_map_metadata 中的通道数不同。如果增益图输入项是单通道，而 gain_map_metadata 指示多通道，则增益图输入项应被视为具有三个相同的颜色通道。如果增益图输入项是多通道，而 gain_map_metadata 指示单通道，则 gain_map_metadata 应被视为多通道，且所有通道具有相同的值。

增益图输入图像应通过在其 ItemInfoEntry 中设置 (flags & 1) 等于 1 来标记为隐藏（hidden）。

在 10.2.6 节中定义的 'tmap' 品牌要求适用于包含色调映射派生图像项的任何文件。

注 1 与不支持色调映射派生的解析器的向后兼容性可以通过将基础输入图像项和 'tmap' 派生图像项放在 'altr' 实体组中来实现。

注 2 ToneMapImage 具有版本（version）字段。这与 ISO 21496-1 的 GainMapMetadata 结构中的 GainMapVersion 字段不同。ToneMapImage 的 version 字段允许对此规范中如何进行色调映射派生进行版本控制。

# 6.6.2.5 颜色格式增强派生 (Colour format enhancement derivation)

# 6.6.2.5.1 定义

具有项类型（item_type）值为 'cfen' 的项是颜色格式增强派生图像项，其重建图像是由一个或多个输入图像形成的，这些输入图像在亮度平面（luma plane）中携带用于重建具有增强颜色格式的图像的组件。

输入图像在 ItemReferenceBox 内使用此颜色格式增强派生图像项的参考类型 'dimg' 进行排序，其中 from_item_ID 的值标识该颜色格式增强派生图像项，且 to_item_ID 的值标识输入图像。reference_count 给出了输入图像项的数量，并且应大于或等于 1。

颜色格式增强派生图像项应：

— 具有 Pixel Information 属性、Image Spatial Extents 属性以及 colour_type 设置为 'nclx' 的 Colour Information 属性。

输入图像项：

— 对于大于 1 的 channel_id，不应指示重复的条目；

— 应各有一个 Pixel Information 属性和一个 Image Spatial Extents 属性；

— 可以有一个 Colour Information 属性，该属性应与颜色格式增强派生图像项的 Colour Information 属性指示相匹配。

颜色格式增强派生图像项应被指示为可显示项。由 reference_count 数组指示的第一项可以被指示为可显示项。由 reference_count 数组指示的所有其余项都应隐藏。

注 颜色格式增强派生图像项和由 reference_count 数组指示的第一项都可以合并到一个 'altr' 替代组中，以表示两个图像项是相互关联的替代项。颜色格式增强派生图像项可以被指示为 'altr' 替代组中的第一项，而该组中的第二项可以存储 4:2:0 编码图像，以允许向后兼容。

num_rows_minus1 加 1 指定了图像中存在的垂直组件分区的数量。

# 6.8.11 'stem' 实体分组

带单声道后备的立体对实体分组（'stem'），在功能上等同于 'ster' 实体分组，但有以下变化：

— 实体组应精确包含三个指向图像项的 entity_id 值。其中前两个值应与 'ster' 实体组的两个 entity_id 值以相同的方式进行解释。

0: 未指定

2: 与右视图同位置（Co-located）

3: 在左视图和右视图之间居中

# 6.8.12 图像金字塔实体组 (Image pyramid entity group)

# 6.8.12.1 定义

盒类型: 'pymd'

容器: 文件级别的 MetaBox 中的 GroupsListBox

强制性: 否

数量: 零个或多个

ImagePyramidEntityGroup 指示一组图像项，该组图像项由基础图像项和一系列渐进合并的概览图像项形成，它们共同构成图像金字塔的层。

ImagePyramidEntityGroup 为图像金字塔的概览图像项和基础图像项内部的单个瓦片（tile）提供整体信息。

概览图像的图像格式应与基础图像相同（即波段数、比特深度、颜色格式等）。

此实体组应包含指向基础图像项和一组概览图像项的 entity_id 值，且不应包含指向轨道的 entity_id 值。这些实体应按从最低分辨率概览图像项到最高分辨率概览图像项的顺序排列，最后是图像金字塔的基础图像项。

flags 字段用于指示与图像瓦片相关的信息。定义了以下 flags 值。

0x000001 tile_info_present_flag：当设置为 1 时，指定存在瓦片信息。当设置为 0 时，瓦片信息不存在，并按下述方式派生。

0x000002 tile_info_constant_flag：当设置为 1 时，指定瓦片大小在图像金字塔的所有层上都是恒定的。当设置为 0 时，瓦片大小在图像金字塔的所有层上可能不恒定。

$tileWidth = tile\_size\_x$ $tileHeight = tile\_size\_y$ $tileColumns = ceil(ispe.image\_width / tileWidth)$ $tileRows = ceil(ispe.image\_height / tileHeight)$

其中 ispe 是与该图像项关联的 ImageSpatialExtentsProperty。

# 6.8.13 区域划分组 (Region partition group)

# 6.8.13.1 定义

盒类型: 'rgpa'

容器: 文件级别的 MetaBox 中的 GroupsListBox

强制性: 否

数量: 零个或多个

区域划分组列出了包含在图像区域内的区域项。该区域是区域划分组覆盖的区域，在图像中定义为一个矩形。

区域划分组通过从图像项到区域划分组的 'rpds' 类型的项参考与包含它所分组的区域项的图像项相关联。

取决于 flags 值，区域划分组覆盖的区域要么在区域划分组结构本身中定义，要么是通过 'rpds' 类型的项参考与区域划分组关联的图像项的区域。

定义了以下 flags 值来描述区域划分组中包含的区域项覆盖的区域：

0x001000, large_field_length：当设置时，指定字段 reference_width、reference_height、top、left、width 和 height 的长度为 32 位。当未设置时，指定字段 reference_width、reference_height、top、left、width 和 height 的长度为 16 位。

0x002000, area_info_present：当设置时，指定字段 reference_width、reference_height、top、left、width 和 height 存在。当未设置时，指定字段 reference_width、reference_height、top、left、width 和 height 不存在。在这种情况下，区域划分组覆盖的区域是与其相关联的图像的区域。

与图像项相关联的区域划分组应仅包含与该图像项或该图像项作为其一部分的另一图像项相关联的区域项。
