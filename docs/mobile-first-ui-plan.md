# 移动优先 UI 重构计划

> 创建日期：2026-07-25
> 目标：优先提升手机单手操作与队列可读性，同时保持 Windows/macOS 宽屏工作流高效。

## 设计原则

1. 手机端的主路径只保留“添加文件 → 查看队列 → 开始/取消转换”三步。
2. 队列项在窄屏使用列表，每项操作的触控目标不小于 Material 默认的 48dp。
3. 设置、详情与次要队列操作使用 bottom sheet / overflow，不与主操作争夺顶栏空间。
4. 宽屏保留照片网格、完整工具栏和更高的信息密度。

## 执行队列

- [x] **1. 现状审查**（完成于 2026-07-25）
  - 确认窄屏仍采用照片网格、14px 卡片操作和拥挤的 AppBar，不适合手机使用。
- [x] **2. 主界面与队列重构**（完成于 2026-07-25）
  - 手机：列表队列、清晰状态、底部“添加 / 开始或取消”主操作栏、更多操作菜单。
  - 桌面：保留网格和完整工具栏，按可用宽度扩展至 3 / 4 / 5 列。
- [x] **3. Sheet 与空状态重构**（完成于 2026-07-25）
  - 手机：设置与详情占用可滚动的大尺寸 bottom sheet；空状态突出单一“添加文件”动作。
  - 桌面：控制 sheet 最大宽度，避免过度拉伸。
- [x] **4. 响应式测试与回归**（完成于 2026-07-25）
  - 新增 390 × 844 窄屏 widget 测试，验证底部主操作栏与非网格布局。
  - `flutter test`：7 / 7 通过。
  - `flutter analyze`：无 error/warning；保留 12 条既有 info（`print` 与字符串插值风格）。
  - Rust 回归沿用本轮 UI 开发前已完成的 `cargo test`：129 通过、3 个 ignored。
