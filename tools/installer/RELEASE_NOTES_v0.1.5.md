# XDRemux v0.1.5

Android 文件导入修复：

- 修复 OPPO/ColorOS 文件选择器返回文件后，HEIC 没有进入转换队列的问题。
- 选取时保留文件字节数据；当 OEM 文件提供方不给出可用本地路径时，自动写入应用私有缓存，再交给 Rust 核心处理。
- 文件选择器返回为空、路径不可读或分类失败时，界面会显示明确状态，不再静默丢弃文件。
- 版本号更新为 `0.1.5+7`，继续使用稳定 release 签名密钥，可直接覆盖升级。

> 已知问题：GitHub Actions 构建的 v0.1.5 APK 还缺少 NDK `libc++_shared.so`，可能导致 Rust 核心无法加载。请使用 v0.1.6 或更高版本。
