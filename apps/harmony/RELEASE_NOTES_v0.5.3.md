# XDRemux 鸿蒙原生版 0.5.3

同步主线 `60b2b48` 与 `release/0.4.6-prep`（`c649570`），共享 Rust 内核升至 `0.4.6`。原生 App 为 `0.5.3` / code `50300`；Flutter 版与原生版独立发布。

## 更新内容

### Live Photo `.pvt` 包

- 队列详情新增「导出 .pvt 包」和「分享 .pvt 包」，与「导出 Live Photo」并列，点一下自动完成识别、配对和打包。
- 鸿蒙的保存选择器和分享面板只能传文件，所以 `.pvt` 包打成单个 `<名称>.pvt.zip`（不压缩，条目带 `<名称>.pvt/` 前缀），与 Flutter 版在鸿蒙上的分享格式一致。在 Mac 上解压得到 `.pvt` 目录，「照片」可直接导入为一张 Live Photo。
- 打包前由 Rust 校验 HEIC 与 MOV 的配对标识，HEIC 与 MOV 字节不变，不重新编码。
- 只开「摄影风格 2」的照片现在也能生成 Live Photo 配对，不再需要改用摄影风格 3 或关闭风格后重新转换。

### 转换单张与导出命名

- 在图库对 Apple 模式下的动态照片点「转换单张」，现在会在队列中只转换这一张（其他项目保持待处理），完成后直接打开它的详情，可导出 Live Photo 或 `.pvt` 包。以前会只保存静态图，丢掉实况部分。普通照片仍直接保存为新图。
- Live Photo 成对导出的 HEIC / MOV 和 `.pvt.zip` 改用原照片的文件名（如 `IMG20260731191303.pvt.zip`），不再使用内部临时名。

### 修复

- 修复图库详情展开照片信息或转换设置面板时，点「完成」等面板下半部分会切换到另一张照片的问题。
- 设置中的两个开关按 Apple 官方名称改为「摄影风格 2」和「摄影风格 3」，说明同步更新。

### Rust 内核 0.4.6

- Live Photo 的 MOV 补写「照片」编辑摄影风格所需的配套轨（线性缩略图、实况信息、风格与质感信息、遮罩），修复开启摄影风格与实况时在「照片」里编辑会退出的问题，摄影风格 2 和 3 都适用；不重新编码视频。
- 安卓实况配对后的 MOV 音频改用 iPhone 的 QuickTime AAC 描述，修复在「照片」里编辑保存后实况部分丢失。
- 摄影风格缩略图改为线性 HDR（Apple Log 码值，增益图作用于像素），鸿蒙上用 10-bit Main10 编码；每张图单独拟合全局色调曲线。
- 修复 MPF 只列主图、没有增益图的 JPEG（如 OPPO Find N5 大师模式实况）无法转换；写入 ISO 21496-1 增益图元数据时拒绝无效数值。

## 安装与升级

- 下载 `XDRemux-HarmonyOS-Native-0.5.3-unsigned.hap`。本包是开发自签用 **Debug unsigned HAP**（`app.debug:true`），Rust 核心保持 Release 优化。
- 应用名 **XDRemux**，包名 `io.github.beetman.xdremux.arkui`，ARM64，版本 `0.5.3` / code `50300`。请使用匹配包名、证书和目标设备的开发 Profile 自签；不是免签安装包或应用市场上架包。
- 现有 `.arkui` 用户使用相同签名可覆盖升级并保留数据；Flutter 和早期 `.native` 版是独立应用身份。
- 以 HarmonyOS 7 / API 26 为开发基准，清单最低兼容 API 18；旧系统仍需按设备验证。
- 附件 `SHA256SUMS.txt` 可用于校验下载文件。

## 验证与使用范围

- Rust 内核回归 299 项通过（3 项忽略）；17 份鸿蒙模型/队列测试（含新增 `.pvt` zip 与导出命名）、5 项 HAP verifier 测试及 C++ PS3 辅助回归通过。生成的 `.pvt.zip` 经 `unzip -t` 与 macOS `ditto` 解压校验。
- HAP 身份/版本/API、Debug 标记和无 HAP Signing Block 检查通过；包内核心导出齐全，桥接层所需的 25 个 `xdremux_*` 符号全部可解析。
- 真机（HUAWEI Pura X View，HarmonyOS 7.0.0.111）：开发自签后覆盖安装并保留数据、启动无崩溃；「完成」不再切换照片；Live Photo「转换单张」只转换一项；`.pvt` 打包完成并弹出保存选择器，建议文件名为原照片名。
- **尚未验证**：在真机上实际保存 `.pvt.zip` 后传到 Mac 导入「照片」、经分享面板发送到其他设备，以及鸿蒙生成的带风格 Live Photo 在「照片」中的编辑效果。
- 转换保持前台运行；人像、摄影风格与 Live Photo 仍含实验能力。未启用可选 libheif 解码器。

原生版本使用独立标签 `harmony-v0.5.3`，不接管 Flutter 版的 Latest 下载入口。
