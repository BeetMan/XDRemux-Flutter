# key1 反推记录（自行推导，未抄上游结论）

分支：`iphone-next` ｜ 样本：`/Users/beet/Desktop/iPhone 18 Pro/` 31 组原生样张
方法：解析原生样张里的 bplist，用统计/自相关/差分反推结构与语义。

> 目标不是复述上游结论，而是**自己从数据推出来**，再与上游对照验证。
> 推导过程中每一步的证据都记在下面。

## 1. 定位

key1 在 styles item 的大 bplist 里，键名就是 `1`：

| 键 | 内容 | 备注 |
|---|---|---|
| `1` | **51840 字节** | **key1 本体** |
| `3` | 516 字节 | 未知 |
| `c` / `d` | 各 2048 字节（1024 个 FP16）| 疑似 LUT |
| `6` | 10 个色调统计字典 | ToneMappedImage / LinearImage / SkinBased / PersonSegmentBased，各含 9 个百分位 |
| `7` | PeopleRatio / SkinRatio / PersonMasksValidHint | |
| `i` | OriginalRangeMin/Max + Gain | 增益范围 |

**证据**：31/31 样张的 key1 都是 51840 字节，但**每个都不相同**
→ key1 是**逐张照片计算**的，不是风格常量。

## 2. 序列化结构（自相关反推）

对 25920 个 FP16 值做自相关：

| k | corr | 含义 |
|---|---|---|
| **30** | **+0.998** | **主周期** |
| 60 / 90 / 120 | +0.99 | 30 的倍数 |
| 4 | +0.63 | 次级周期 |
| 其余 | ≈ -0.11 | 噪声 |

`25920 / 30 = 864 = 12 × 9 × 8`

**结论**：布局是 **`(12, 9, 8) 个 cell × 每 cell 30 值 (10×3)`**，
即 `12 × 9 × 8 × 10 × 3`（C 序）。

> 与上游声明的形状一致 —— 但这是我们**从自相关独立推出**的，
> 顺便验证了上游数字（51840 = 25920 × FP16）。

## 3. 单个 cell 的语义（逐值观察）

30 值 = 10 行 × 3 列，形态高度规整：

```
[ 0] +0.011  +0.014  +0.009   ← 偏移量
[ 1] +1.010  +0.030  +0.041   ← 矩阵第 1 行
[ 2] +0.041  +1.008  +0.080   ← 矩阵第 2 行
[ 3] +0.001  +0.004  +0.916   ← 矩阵第 3 行
[ 4..9] -0.026 ~ +0.011       ← 小系数
```

**所以每个 cell = 仿射色彩变换**：

```
out_rgb = M · in_rgb + offset
```

其中 **前 4 行（12 个值）= 3 个偏移 + 3×3 矩阵**，后 6 行（18 值）是小系数。

## 4. 与上游常量对照（重要验证）

上游 `apple_photographic_styles.rs` 的常量：

```rust
IDENTITY_INDICES: [usize; 3] = [3, 7, 11];
DIRECT_PARAMETER_INDICES: [usize; 6] = [0, 1, 2, 3, 7, 11];
LINEAR_BOUND: f64 = 1.0 / 8.0;
QUADRATIC_BOUND: f64 = 1.0 / 16.0;
```

**我们的数据独立解释了这些数字的由来**：

12 参数展平 = `[off_R, off_G, off_B, M00, M01, M02, M10, M11, M12, M20, M21, M22]`

- 对角元在展平索引 **3, 7, 11**（= 3+0, 3+4, 3+8）→ `IDENTITY_INDICES` ✓
  **恒等变换的对角线**
- 直接可控参数 `[0,1,2, 3,7,11]` = 3 个偏移 + 3 个对角元 → `DIRECT_PARAMETER_INDICES` ✓
- `LINEAR_BOUND = 1/8` 对应矩阵偏离恒等的幅度；
  `QUADRATIC_BOUND = 1/16` 对应二次项幅度

**这不是巧合**：上游的 12 系数多项式基，就是把「偏移 + 3×3 矩阵」这 12 个数
当作可学习/可优化的参数。

## 5. 统计验证

31 张样张的对角元（恒等应为 1.0）：

| 通道 | mean | std | 说明 |
|---|---|---|---|
| R-diag | 0.9978 | 0.0328 | ≈ 恒等 |
| G-diag | 0.9847 | 0.0282 | 略低 |
| **B-diag** | **0.9691** | 0.0298 | **低 3%** |

三个轴（12/9/8）都承载变化（std ≈ 0.015），说明 3D 索引都有效。

**Standard 风格 ≈ 恒等变换**（微调），B 通道略微降低 —— 与"Standard 是接近原图
的基准风格"这一直觉一致。

## 5.5 A4 —— 后 6 行（rows 4-9）的语义（31 样本合并）

### 量级结构

| 部分 | 行 | mean/std | max\|.\| | 占比 |
|---|---|---|---|---|
| 偏移 | row 0 | 0.039 | 0.549 | |
| 线性 3×3 | rows 1-3 | 0.35 | **3.271** | 1 |
| 「二次」 | rows 4-9 | 0.02-0.055 | 1.556 | **0.098** |

**二次块能量是线性块的 ~1/10**，与"二次项是高阶小量"一致 ✓

### 关键否定发现：上游的界不是值域界

```
max|线性| = 3.271   （远超 LINEAR_BOUND = 1/8 = 0.125）
max|二次| = 1.556   （远超 QUADRATIC_BOUND = 1/16 = 0.0625）
```

**所以 `1/8` / `1/16` 不是 key1 存储值的界**，而是生成 key1 时
**系数 delta / 用户参数**的界（对应 `apple_style_data_from_coefficient_deltas()`）。
抄结论会误以为存值受限 —— 这是自己推导的直接价值。

### 二次块内部结构（6 行之间的相关）

```
      r0    r1    r2    r3    r4    r5
r0: +1.00 +0.79 +0.24 +0.50 -0.12 -0.61
r1: +0.79 +1.00 +0.16 +0.82 +0.10 -0.68
r2: +0.24 +0.16 +1.00 -0.05 +0.37 +0.31
r3: +0.50 +0.82 -0.05 +1.00 +0.44 -0.49
r4: -0.12 +0.10 +0.37 +0.44 +1.00 +0.51
r5: -0.61 -0.68 +0.31 -0.49 +0.51 +1.00
```

- **r0 / r1 / r3 正相关组**（+0.79, +0.82, +0.50）
- **r5 与它们反相关**（-0.61, -0.68, -0.49）
- r2、r4 自成结构

### 「每 2 行一个输出通道」假设被否定

| 配对 | corr | 结论 |
|---|---|---|
| row4↔row5 | +0.79 | ✓ |
| **row6↔row7** | **-0.05** | **✗ 不成立** |
| row8↔row9 | +0.51 | ? |

所以 rows 4-9 **不是**按输出通道 (R,G,B) 两行一组排列的。

### 通道结构差异（有意思）

| 块 | 3 列之间相关 |
|---|---|
| 线性矩阵 | **-0.43 ~ -0.49**（负相关）|
| 「二次」块 | **+0.90 ~ +0.93**（高度正相关）|

→ 二次修正三通道**同向**，线性矩阵三通道**此消彼长**。
这符合"线性部分做色彩平衡、二次部分做整体色调曲线"的直觉。

### 网格位置

三个轴上的二次能量都有变化（std ≈ 0.033），但不主导；
同 cell 内线性能量与二次能量相关 +0.63 —— **同一风格调整的两部分**。

### 当前结论

- ✅ rows 4-9 是**高阶修正项**（能量约线性的 1/10）
- ✅ 与上游"多项式基"描述相容
- ❌ 但**不是**简单的「6 交叉项 × 3 输出通道」分组
- ❌ 上游的 1/8、1/16 **不是存值界**

**待定**：rows 4-9 的确切索引语义。需要 **(输入色, 输出色) 配对数据**
才能拟合验证 —— 即需要同场景不同曝光/风格的样张（与 A4 未解决项一致）。
