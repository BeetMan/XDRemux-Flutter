# XDRemux v0.1.8

Android 后台转换与体验优化：

- **后台转换**：前台服务保持转换在后台继续运行，通知栏实时显示进度（多文件并行时显示当前转换的文件名）。首次转换时引导设置电池优化白名单（含 OPPO 耗电行为控制直达入口）。
- **跳过已转换文件**：入队时自动检测输入文件是否已是转换后的 ISO HDR 照片，跳过并提示"已是转换后的 HDR 照片"，避免产生不可用的套娃转换。
- **一键保存到图库**：三点菜单新增"全部保存到图库"，按拍摄模式分相册（大师模式/人像/夜景等）。
- **进度条改进**：主进度条汇总所有并行转换的进度；每个队列项有独立进度条；并发模式改用平滑渐近曲线。
- **队列卡片交互简化**：点击已完成卡片直接弹出操作（保存到图库/分享/打开），点击失败卡片直接重试，不再有多余的详情页。
- **设置页**：去掉"高级"折叠区；新增"后台转换"入口（直达 OPPO 耗电行为控制）；新增缓存和输出目录管理（显示大小，一键清除）。
- **Android 分目录改分相册**：开启"按拍摄模式分相册"后，保存到图库时按 Pictures/大师模式 等分相册，不再在文件系统创建子目录。
- **修复**：清除输出目录后自动重建子目录；清除缓存不影响后续使用。

版本号 `0.1.8+10`，继续使用稳定 release 签名密钥，可直接覆盖升级。
