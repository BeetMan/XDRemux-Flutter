## 上游 v1.3 概况

### 结构变化

上游从单文件 `xdremux/swift-cli/XDRemux.swift`（~4800 行）重构为 SwiftPM 包：

| 路径 | 内容 |
|------|------|
| `Sources/XDRemuxCore/` | 转换核心：HDRPipeline、ISOBMFF、OutputValidation、Batch、PhotoCategorization |
| `Sources/XDRemuxAppleFeatures/` | Apple 特性：摄影风格（~6,500 行）+ 人像模式（~5,600 行） |
| `Sources/XDRemuxCLI/` | CLI 前端 |
| `xdremux/python/` | Python CLI 保留，仅标准转换 + 分类，不含 Apple 功能 |

### 新功能清单

| 功能 | 规模 | 是否适合我们 |
|------|------|--------------|
| 拍摄模式分类 `categorize` | 538 行 Swift + 312 行 Python | ✅ 纯逻辑，可移植到 Rust + Flutter |
| Apple 摄影风格 `--apple-photographic-styles` | ~6,500 行，依赖 Vision/CoreImage/VideoToolbox | ❌ 跳过（macOS 专属，Rust 重写不可行） |
| Apple 人像模式 `--apple-portrait` | ~5,600 行，同样依赖 Apple 框架 | ❌ 跳过（同上） |

### 核心转换层改进（可同步）

1. **EXIF 方向处理**：主图 EXIF orientation ≠ 1 时，gain map 需同步 transpose，tmap 的 ispe 按 irot 旋转取值（`makeImageIOCanonicalTmapIspeBox`），irot box 写入正确 quarter-turns。**我们 Rust 目前完全未处理，旋转照片输出会错位。**
2. **OppoCompatibility 扩展**：4 值 → 7 值（新增 `iso` / `isoNoLocal` / `isoGraph`），新增 flag 常量 `isoUltraHDRFlag = 0x00200000`、`localHDRFlag = 0x00040000`。
3. **OppoCameraTail 尾部策略**：10 级粒度（off / watermark / compact / preserve / preserveWithoutPortrait / preserveWithoutPortraitOrPrivateHDR / preserveWithoutPrivateUHDR / preserveWithoutPrivateHDR / preserveNoUHDR / preserveNoHDR）。我们目前只有"全保留 / 过滤 HDR"两档。
4. **增益图属性修正**：单通道用 `pixiMono8`，三通道用 BT.601 colr（`isoColrUnspecifiedBT601Box`）。我们目前一律 RGB8 + sRGB。
5. **严格 ISO tmap**：`TmapFormat.strict` 在 62/142 字节 ImageIO tmap 的 flags 字节后补 3 个保留字节 → 65/145 字节，符合 ISO 21496-1 C.2.2。
6. **防降质检查**：`rejectLossyGainMapPromotion` — 输入已是 4:2:0 增益图时拒绝非兼容模式的 4:4:4 "升质"（色度信息已丢失，升质无意义）。
7. **编码质量基线**（`docs/validation/encoding-quality-pareto-20260718.md`）：gain map 0.90 / 512 tile 确认为 Pareto 最优（与我们当前一致）；修复过 tile 高度非整数倍时图像偏移 4 行的 bug（Quartz padding 在上、grid crop 在上导致错位）——**需排查我们 Rust `tile_and_encode` 的边缘复制填充是否有同类问题。**

## 同步计划与状态

### P0 — 正确性修复（影响现有输出质量）

- [x] **1. EXIF 方向支持** ✅ 已完成
  - Rust `exif.rs`：新增 `ExifOrientation` 枚举（8 方向）、`read_heif_exif_orientation()`、`irot_quarter_turns_ccw()`、`swaps_axes()`、`output_dimensions()`
  - `isobmff_write.rs`：gain map 像素按方向 transpose（`orient_gainmap_pixels`）、tmap ispe 经 `make_imageio_canonical_tmap_ispe_box` 旋转取值、irot box 写入正确 quarter-turns；primary 已有 irot 时以 primary 为准
  - 测试：`write_lhdr_uses_exif_orientation_for_irot_and_tmap_dimensions`
- [x] **2. 增益图属性修正** ✅ 已完成
  - mono gain map 用 `PIXI_MONO8_BOX`；3 通道 gain map tile colr 用 `COLR_UNSPECIFIED_BT601_BOX`，grid 保持 sRGB
- [x] **3. tile 边缘填充排查** ✅ 无此 bug
  - 上游 bug 是 Quartz padding 在上 + grid crop 在上导致偏移 4 行；我们 `tile_and_encode` 填充在下/右、grid 也不裁剪（直接按真实尺寸写），方向一致，无同类问题

### P1 — 拍摄模式分类（跨平台新功能）

- [x] **4. Rust `categorize` 模块** ✅ 已完成（`xdremux/rust/src/categorize.rs`，新增）
  - 15 种 `CaptureMode` 位定义与上游一致（master=0x100000000 … beauty=0x2, normal=0）
  - UserComment 提取：`Oplus_/oplus_/Oppo_/oppo_` 前缀 + JSON `oplustag` 兜底 + TIFF 0x9286 解析
  - `KNOWN_FLAGS_MASK`（bits 0-32 + bit 62）+ unknown-flags 状态
- [x] **5. FFI 暴露** ✅ 已完成
  - `xdremux_classify(path)` → `ClassificationResult`（modeKey / folderName / status）+ `xdremux_free_classification_result`
- [x] **6. Flutter UI 集成** ✅ 已完成
  - 队列项显示拍摄模式标签（`captureModeLabel` / `classificationLabel`）
  - 设置增加"按拍摄模式分目录输出"开关（`categorizeOutputByMode`，写入 `ConversionConfig` 并持久化）
  - 输出路径按 folderName 分目录（`app_models.dart` 中 `outputPathFor` 支持）
  - ⬜ 独立"整理照片"页（扫描 → 预览 → 复制分类）——**未做，可选**
