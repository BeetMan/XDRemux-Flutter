# XDRemux v0.4.0-pre.5

这是 v0.4.0 的第 5 个预发布测试版本，重点解决 Apple 摄影风格在全平台硬解兼容性及空间光照图动态渲染问题。

## 本版本更新

- **Apple 摄影风格核心管线升级**：
  - **动态光照图生成**：在生成线性缩略图并解码主图像素时，直接根据原图真实 RGB/Luma 区域亮度分布动态计算 32×32 的 	oneLightMap（键 c）与 linearLightMap（键 d），并自适应 EXIF 方向存储，iOS 照片 App 编辑摄影风格时的调色与遮罩完美贴合实际照片元素。
  - **清除水印白边断层残留**：彻底修复历史兜底常量中因含有 OPPO 水印白框导致画面底部 12.5% 颜色断层/过曝的问题。
  - **自适应 Delta Grid 瓦片排布**：横屏采用 5×6 瓦片网格，竖屏自适应调整为 6×5 瓦片网格，完整覆盖不同纵横比画面。
  - **硬解兼容性保障**：主图与缩略图全面统一使用标准 4:2:0（Chroma Format IDC = 1）编码，彻底解决安卓/OPPO 等手机图库硬件解码黑屏问题。
- **底层与测试**：
  - 补充 ExifOrientation::to_u16 方向转换与 IEEE 754 Float16 快速转换单元测试。
  - 核心库与 Conformance 141 个单元测试全量通过。

## 验收重点

1. **iOS 摄影风格**：在 iPhone 照片 App 中编辑转换后的成片，滑动切换各类摄影风格（冷色调、琥珀色、鲜明等），确认画面从顶到底过渡自然，无任何底部水平分界线。
2. **OPPO / 安卓图库硬件解码**：在 OPPO 等安卓手机自带相册打开成片，确认不再黑屏且能正常硬解显示。
3. **不同比例与方向照片**：测试横屏、竖屏以及不同裁剪比例的样张转换，验证 Delta Grid 瓦片与光照图自适应效果。
