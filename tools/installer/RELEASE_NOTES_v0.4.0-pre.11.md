# XDRemux v0.4.0-pre.11

这是 v0.4.0 的第 11 个预发布测试版本，在 pre.10 人像大修的基础上做两项一致性修正与仓库清理。功能行为与 pre.10 基本一致，但人像的渲染参数计算更准确。

## 本版本更新

- **人像渲染参数与深度平面保持一致**：
  - pre.10 引入的每张照片深度曲线标定，会把该场景自身的 rank 范围拉伸到目标视差区间；但负责生成 Apple 渲染参数（REND）的焦点计算仍沿用旧的未拉伸归一化，两者对同一像素的理解不一致。
  - 具体影响：当场景 rank 落在 40–200、而焦点位于 rank 200 时，深度平面把该像素放在视差 0，REND 却算出 0.216，使渲染激活值系统性偏高（相对可达数十个百分点）。
  - 现在焦点值与深度平面走**同一套归一化变换**，REND 与它所描述的像素一致。

- **停用 conformance 人像镜像**：
  - `xdremux-conformance` 的人像模块是曲线标定**之前**的实现快照，缺少每张照片深度曲线、缺少拉伸映射，而底图来源选择位于核心库、镜像根本无法复现。
  - 同一工具链的 `portrait-depth` 诊断却**是**最新的，两者混用会得出误导性结论。因此该子命令现在**直接报错拒绝执行**，并给出明确指引；人像转换请使用核心库或应用本体。

- **仓库清理（不影响产物）**：
  - `apps/flutter/third_party/ohos/` 的 215 个 vendored 文件改为不再跟踪 —— 它们本就可由 `tools/ohos/fetch_plugins.sh` 重建，此前被跟踪只是因为早于对应的忽略规则存在。
  - 鸿蒙 hap 构建会重写 macOS 的插件注册文件（鸿蒙 pubspec 的插件集不同），现在构建脚本在结束后自动用主 pubspec 恢复，工作树保持干净。

## 验收重点

1. **人像光圈**：确认光圈拨杆可用，f/1.4 与 f/16 之间有可见且自然的虚化差异，且不出现全黑。
2. **关闭人像 = 清晰原图**：干净、未虚化、无水印，方向正确。
3. **HDR 与实况照片**：确认无回归。

## 说明

- 本版本与 pre.10 的主要差别在于渲染参数的计算一致性；已通过 pre.10 验收的人像流程无需重新学习。
- 鸿蒙 hap 仍为本地构建的 unsigned 包（签名是侧载工具的事）。
