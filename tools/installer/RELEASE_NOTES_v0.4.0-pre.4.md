# XDRemux v0.4.0-pre.4

这是 v0.4.0 的第 4 个预发布测试版本，主要用于验证天玑平台设备兼容性、人像重构修复及近期多平台稳定性优化。

## 本版本更新

- **核心与容器适配**：
  - 完善 OPPO 尾部扩展区识别，支持 5 字节 \x00jxrs 与向后反向扫描，兼容天玑等平台的新格式容器。
  - 修复 Ultra HDR JPEG 人像重构时底图覆盖导致人像算法输入失效的问题，保留完整未调色源图供算法执行。
  - 修复 HEIF 非标准/越界 EXIF Orientation 方向值容错（钳位回 Normal，防止解码异常崩溃）。
- **界面与体验优化**：
  - 修复桌面端处理状态浮层布局偶发崩溃问题（Positioned in Column）。
  - 修复设置面板中动态照片（Live Photo）默认策略未能正常持久化生效的问题。
  - 优化照片队列卡片展示，精简多余机型标签。
  - 完善中英双语国际化文案支持。
- **CI 与工程维护**：
  - 优化多架构 Windows 构建与发布流水线同步。

## 验收重点

1. 天玑平台 OPPO 样张（含 HEIC、JPEG、实况与人像）在各平台客户端上的导入、解析与转换。
2. Ultra HDR JPEG 人像虚化重构输出质量与虚化效果验证。
3. 桌面端（Windows / macOS）长队列批处理稳定性与设置持久化。
