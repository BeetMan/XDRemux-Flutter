# XDRemux v0.4.0-pre.9

这是 v0.4.0 的第 9 个预发布测试版本，重点修复人像模式与摄影风格同时开启时能力丢失的问题，并修正人像深度蒙版与焦点相关的几何/元数据缺陷。

## 本版本更新

- **修复「摄影风格 + 人像模式」同开后人像只有开关、无拨杆/选项的问题**：
  - 根因：摄影风格步骤会重建并替换 MakerNote，把人像所需的 58 项 Apple 人像元数据覆盖为仅 2 项的 Styles 元数据。
  - 修复：在保留完整 Apple 人像 MakerNote（含 UUID、未知标签与演示样式标志）的前提下，仅合并 Styles 必需字段；完整支持的人像笔记保持字节级不变。
  - 对于不完整的 Apple 笔记，新增安全的目录合并路径，并在遇到无法验证的内部偏移（未知 out-of-line UNDEFINED、IFD/IFD8 目录指针等）时明确失败关闭，避免静默损坏。

- **修正人像 EXIF 标记写入**：
  - 原代码误将 `CustomRendered = 9` 写入 `DigitalZoomRatio (0xA404)` 并使用了错误类型，导致数码变焦比例被意外改写。
  - 现在正确写入 `CustomRendered 0xA401, SHORT, count 1, value 9`，同时完整保留 `DigitalZoomRatio 0xA404` 原值。

- **修正 OPPO 水印照片的蒙版几何**：
  - 识别部分 OPPO 机型底部水印的打包格式（`hassel_style_1`），正确得到照片内容区域 `(0,0,3072,4096)`，避免深度/人像蒙版错误覆盖底部水印条带。
  - 保留原有对齐对称水印布局的兼容解析；无法识别或非法布局时回退到全帧处理。

- **修正焦点坐标重复归一化**：
  - 原代码在旋转/裁切后将已归一化的焦点坐标再次除以主图尺寸，导致 XMP 焦点接近左上角，影响景深定位。
  - 现在统一一次坐标变换，与深度/蒙版的旋转、中心裁切、水印填充共享同一几何路径。

- **新增 14 项 Rust 单元回归测试**：
  - 人像几何：打包/传统水印识别、负向非法用例、样本焦点/填充、逆裁切、旋转/光栅对应、共享深度与蒙版裁切窗口。
  - 元数据合并：LE/BE、UUID 与未知字段保留、类型化偏移重定位、不透明扩展拒绝、完整不透明笔记字节级保留、样式独占双标签路径、IFD/IFD8 目录指针拒绝、非法头/目录/载荷边界拒绝。

## 验收重点

1. **人像模式单独开启**：选择人像模式照片，确认转换后 Apple 相册仍显示光圈拨杆并允许调整景深。
2. **摄影风格 + 人像模式同开**：确认转换后既能编辑摄影风格，也能看到并使用完整人像光圈/选项。
3. **水印区域不被错误虚化**：对带底部水印的 OPPO 人像照片，确认背景虚化不会蔓延到水印条带。
4. **焦点位置准确**：确认人像主体背景虚化方向符合拍摄焦点，不会把焦点错误放在画面角落。
5. **Live Photo / 照片详情等 pre.8 功能保持可用**：实况照片合成、照片详情弹窗、修改参数后重新转换等前期功能不发生回归。
