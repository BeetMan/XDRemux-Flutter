# XDRemux v0.1.9-pre.1

预发布版本——转换提速与体验优化，请先在小范围验证：

- **转换提速 ~1.9x**：x265 全平台开启 SIMD 汇编（AVX2 / NEON），实测 9MB ProXDR HEIC 从 16.0s 降到 8.6s。Android 端同步生效（arm64 NEON）。
- **转换完成后自动保存到图库**（Android）：设置页新增开关，批量结束后自动存入 Pictures，遵循"按拍摄模式分相册"。
- **分享接收提示**（Android）：从相册/文件管理器分享文件进来时弹 SnackBar 确认接收数量。
- **通知点击跳回 App**：转换完成通知点击后拉起/聚焦应用（Windows toast + Android）。
- **Windows 系统托盘**：三点菜单"最小化到托盘"，批量转换时托盘 tooltip 实时显示进度（N/M 完成），左键恢复窗口，右键菜单显示/退出。
- **Windows 打开输出目录**：标题栏新增一键直达按钮，不用再进三点菜单。

签名与 v0.1.7/v0.1.8 一致，可直接覆盖安装。版本号 `0.1.9+11`。

预发布不会触发应用内更新提示；验证无问题后会以 v0.1.9 正式发布。
